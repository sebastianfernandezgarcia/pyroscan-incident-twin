## Approved competition mix: Cosmic Pulse

The V4 competition mix uses **Cosmic Pulse**, an instrumental generated by the
project owner in their Magnific Personal workspace with Google Lyria 3 Pro on
2026-09-03:

- Creation page: <https://www.magnific.com/app/creation/0et1AYiTfW>
- Original working copy: `webMcpClaude/video/public/music-src.mp3`
- Normalized, crossfaded 170-second master:
  `webMcpClaude/video/public/music.m4a`
- Master SHA-256:
  `f69b85cd810c8f5a13488adbc6f2aeae20b0ab5cf38d3e42b6fc783722eb4191`
- Local media-use asset: `.media/audio/bgm/bgm_003.m4a`

The master is AAC stereo at 96 kHz, exactly 170 seconds, measuring −17.1 LUFS
integrated and −1.0 dBFS true peak before the film mix. The final mixer extends
its four-second shortfall with a four-second crossfade into the opening, fades
the programme tail, targets the bed at −30 LUFS before gain and narration
ducking, and keeps the spoken English narration dominant.

The source files and `.media` copy are intentionally not committed to the public
repository. This record identifies the user-supplied/generated asset and its
provenance without making any additional third-party licensing claim.

After resolving the master as `bgm_003`, reproduce the approved low-level mix
from the film directory with:

```bash
./scripts/assemble_voiceover.py \
  --video renders/pyroscan-visual-master-v2-4k.mp4 \
  --takes voiceover/takes \
  --music .media/audio/bgm/bgm_003.m4a \
  --music-lufs -30 \
  --music-weight 0.75 \
  --music-duck-ratio 10 \
  --music-tail crossfade \
  --output renders/pyroscan-webmcp-final-v4-cosmic-pulse-4k.mp4
```

## Reproducible fallback bed

`pyroscan-tech-bed-v2-musical.wav` is a deterministic, original 174-second
musical technology bed generated entirely from synthesis defined in
`../scripts/generate_tech_bed.py`.

The approved musical direction replaces the original amorphous drone with a clear 104 BPM
pulse, glassy arpeggios, bass, restrained synthetic percussion, transition
motifs and scene-aware energy. It remains deliberately quiet under narration.

It contains no samples, vocals, third-party composition, or licensed catalog
material. The WAV is intentionally ignored because it is reproducible and is
about 48 MB. Generation requires Python 3 and NumPy.

Regenerate and register it locally:

```bash
./scripts/generate_tech_bed.py \
  --duration 174 \
  --output media-source/pyroscan-tech-bed-v2-musical.wav

node ~/.agents/skills/media-use/scripts/resolve.mjs \
  --type bgm \
  --intent "Original animated musical PyroScan technology bed" \
  --from media-source/pyroscan-tech-bed-v2-musical.wav \
  --project .
```

The final voice/music mix is created by `../scripts/assemble_voiceover.py`.
The fallback defaults to −26 LUFS before the narration sidechain; the Cosmic
Pulse render explicitly uses −30 LUFS, a 0.75 final music weight, and a 10:1
sidechain ratio. Both paths cap the finished programme at −1.5 dBTP.
